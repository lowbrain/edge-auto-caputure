============================================================
 edge-auto-capture 使い方（配布版）
============================================================

■ これは何？
 Microsoft Edge で見ているページを、記録ONの間だけ、そのときの画面を
 まとめて保存するツールです。保存されるのは次のとおりです。
   ・フルページのスクリーンショット （.png）
   ・ページの全文テキスト           （.txt）
   ・ページの一部だけのテキスト     （_part.txt）※CSSセレクタを入れたときだけ
 いつ撮るかはあなたが操作します。ページ上部のバーで「記録開始／停止」
 「今すぐ1枚」などを操作できます。

■ 動作条件
 - Windows
 - Microsoft Edge がインストール済みであること
   （Windows 11 なら標準で入っています）
 - Python は不要です（このフォルダだけで動きます）

■ 準備（先に必ずお読みください）
 - 配布された ZIP は、必ず「すべて展開（すべて解凍）」してから使ってください。
   ZIP の中身を開いたまま exe をダブルクリックしても正しく動きません
   （_internal を読み込めず、何も起きずに終了することがあります）。
 - 展開したフォルダは、自分が書き込みできる場所に置いてください。
   Program Files など権限のない場所に置くと、保存やログの作成に失敗し、
   ダブルクリックしても何も起きないことがあります。
   デスクトップやドキュメントなど、書き込める作業フォルダを推奨します。

■ 使い方（3ステップ）
 1. 同じフォルダの config.ini をメモ帳などで開き、必要なら設定します。
      start_url        … 起動時に最初に開くページ（例: https://www.google.com）
      output_dir       … 保存先フォルダ（既定: この exe と同じ場所の output）
      start_recording  … 起動直後に記録を始めるか（false=待機で起動 / true=最初から記録）
      target_selector  … ページの一部を抜き出すときの CSS セレクタ（任意。空でもOK）
    ※ 変更したら上書き保存してください。設定を変えなくてもそのまま動きます。

 2. edge-auto-capture.exe をダブルクリックします。
    自動で Edge が開きます（黒いコンソール窓は出ません）。
    画面の上部にバーが表示され、次のように操作できます。
      ・「記録開始」 … ここから記録ON。以後ページが変わるたびに自動保存します。
      ・「記録停止」 … 記録OFF（待機）に戻ります。以後は自動保存しません。
      ・「今すぐ1枚」 … 記録ON/OFF に関わらず、今のページを1回だけ保存します。
      ・目のアイコン（バー右端） … バーを半透明にして、下に隠れているページ内容を確認できます（もう一度押すと元に戻ります）。
    記録中はバーが赤く「記録中」、待機中は灰色で「待機中」と出ます。
    既定では待機（記録OFF）で起動します。撮り始めたいときに「記録開始」を押してください。
    ※ このバーは、保存される png / txt / _part.txt には写り込みません。そのまま使えます。

 3. 開いた Edge で、普通どおりページを見てください。
    記録ONの間は、ページが移動するたびに output フォルダへ png と txt が自動保存されます。

■ 中身だけ変わるページ（SPA）を撮りたいとき
 検索の絞り込みやタブ切替など、URL が変わらないのに中身だけ変わるページは、
 上の「ページ移動」では撮れません。そのときはバーの次の機能を使います。
   1. 右側の「SPA検知」スイッチを ON にします（セレクタが空でも押せます）。
      セレクタ未入力のときは、ページの主要部（本文）の変化を自動で監視します。
   2. 特定の部分だけを監視したいときは、「CSSセレクタを入力」欄に CSS セレクタを入れます。
      （書き方・調べ方は下の「CSSセレクタの入れ方」を参照）
   3. 記録ONの間、その中身が変わって落ち着くたびに自動保存されます。
      （同じ内容のときは重複して保存しません）
 ※ セレクタが空でも、ページの主要部の変化で自動保存されます。

■ CSSセレクタの入れ方（抜き出し・SPA検知の対象）
 「CSSセレクタを入力」欄は、ページの中の「どの部分」を対象にするかを指定します。
 一部抜き出し（_part.txt）と SPA検知の両方で、同じ値を使います。
 一致する部分が複数あれば、そのすべてが対象になります。

 ● よく使う書き方（例）
    #main         … id が main の部分（<div id="main"> など）
    .price        … class が price の部分（<span class="price"> など）
    article       … <article> の部分（タグ名で指定）
    #main .title  … main の中にある title クラスの部分
    h1, .price    … h1 または price（カンマで複数）
   ※ id は先頭に「#」、class は先頭に「.」を付けます。

 ● 調べ方（Edge の開発者ツール）
    1. 対象の部分を右クリック →「検証」（または F12）を開きます。
    2. Elements で青く選ばれている行の id / class を確認します。
    3. id があれば「#その値」、class があれば「.その値」を入力欄に入れます。
   （入力欄にマウスを乗せると、この手順がヒントとして表示されます）

 ● 当たっているか確認
    入力欄の右に「一致 N件」と出ます。
    「一致 0件」（黄色）は、どこにも当たっていません。
    「無効な指定」（黄色）は、書き方が壊れています。
    どちらの場合も、1件以上になるように直してください。

 ● コツ
    ・右クリック → Copy → Copy selector で出る「長い指定」は壊れやすいので、
      できるだけ短い #id や .class にするのがおすすめです。
    ・SPA検知で撮りすぎる（時計や広告など動き続ける部分に反応する）ときは、
      「CSSセレクタを入力」欄に見たい部分だけを指すセレクタを入れて範囲を絞ってください。

■ 保存先
 既定では exe と同じ場所の output フォルダに保存されます。
 別の場所へ保存したいときは、config.ini の output_dir に
 絶対パス（例: C:\Users\名前\Desktop\capture）を指定してください。

■ ログイン状態を引き継ぎたいとき（上級者向け）
 毎回、ログインし直すのが手間な場合は、config.ini の profile_dir に
 フォルダを指定できます。このフォルダにログイン状態を保存し、
 次回起動時に引き継ぎます。空のままなら毎回まっさらな状態で起動します（既定）。
   例: profile_dir = profile
 ※ 注意: 指定したフォルダには Cookie や認証情報がそのまま保存されます。
    共有 PC や他人が見られる場所には置かないでください。
    不要になったらフォルダごと削除してください。

■ 止め方
 開いている Edge のウィンドウを閉じるだけです。
 このツールが起動した Edge の終了と、一時データの掃除まで自動で行います。
 （キー操作などは不要です）

■ うまくいかないとき
 - 保存先（output）フォルダにできる log.txt に、動作の記録が残ります。
   「保存されない」「起動してすぐ終わる」ときは、このファイルを開いて確認してください。
 - 設定の誤りや Edge が見つからない場合などは、内容を知らせる小さなダイアログが出ます。
   メッセージにしたがって config.ini を見直してください。

■ 初回起動時の注意
 署名のないプログラムのため、初回は Windows SmartScreen の警告が出ることがあります。
 その場合は「詳細情報」→「実行」で起動できます。
 また、_internal フォルダは動作に必要です。削除・移動しないでください。
 なお、ZIP を展開せずに実行したり、権限のない場所に置いたりすると起動しません。
 詳しくは上の「準備」をご覧ください。
