============================================================
 edge-auto-capture 使い方（配布版）
============================================================

■ これは何？
 Microsoft Edge で開いたページの URL / タブが変わるたびに、
 フルページのスクリーンショット(.png)とページ全文テキスト(.txt)を
 自動で保存するツールです。

■ 動作条件
 - Windows
 - Microsoft Edge がインストール済みであること
   （Windows 11 なら標準で入っています）
 - Python は不要です（このフォルダだけで動きます）

■ 使い方
 1. 同じフォルダの config.ini をメモ帳などで開き、必要に応じて設定します。
      start_url       … 起動時に最初に開くページ（例: https://www.google.com）
      output_dir      … 保存先フォルダ（既定: この exe と同じ場所の output）
      target_selector … ページの一部だけ抜き出したい場合の CSS セレクタ（任意）
    ※ 変更したら上書き保存してください。編集しなくてもそのまま動きます。

 2. edge_auto_capture.exe をダブルクリックします。
    Edge が新しいプロファイルで起動し、コンソール窓に
    「Edge を起動しました。…」と表示されます。

 3. 開いた Edge で普通に閲覧してください。
    ページを移動するたびに output フォルダへ png と txt が保存されます。

■ 保存先
 既定では exe と同じ場所の output フォルダに保存されます。
 別の場所に保存したい場合は config.ini の output_dir に
 絶対パス（例: C:\Users\名前\Desktop\capture）を指定してください。

■ 停止方法
 - Edge のウィンドウを閉じる、または
 - コンソール窓で Ctrl + C を押す
 停止すると、このツールが起動した Edge の終了と一時データの掃除まで行います。

■ 初回起動時の注意
 署名のないプログラムのため、初回に Windows SmartScreen の警告が出ることがあります。
 その場合は「詳細情報」→「実行」で起動できます。
 また、_internal フォルダは動作に必要です。削除・移動しないでください。
