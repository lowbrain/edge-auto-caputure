## 残タスク（いずれも「後回しでよい」枠）

> **2026-08-15: 下記 3 件（D-B2 / D-C3 / exe バージョン埋め込み）を対応済み。**
> 実装内容は下の各項と git 履歴を参照。ここに未対応の「後回し」枠タスクはもう無い。
> 都度対応（AV 誤検知・サイズ実測・`output/` 同梱）と組織判断（D-D1 証明書）だけが残る。

### D-B2. 環境情報を起動ログへ〔済〕

起動時に **OS・Python・実行形態（exe/script）・基準フォルダ**（`infra.startup_environment_line`）、
**実際に採用された設定値**（`config.summarize_config`）、**採用ブラウザの実バージョン**
（`context.browser.version`）を log.txt へ 1 行ずつ出す。`channel="msedge"` は環境の Edge に
依存するため、Edge 側の更新で挙動が変わっても log.txt だけで版・採用設定を追える。

### D-C3. config.ini の自己修復〔済〕

削除・欠損時は既定 config.ini（`config.DEFAULT_CONFIG_TEXT`＝配布 `config.ini` と同一。
drift はテストで担保）を書き出して既定値で起動する。破損／`[capture]` セクション無しの場合は
元ファイルを `config.ini.invalid` へ退避してから作り直す（ダイアログで通知）。書けない場所でも
メモリ上の既定値で起動する。**値だけが不正**（数値の編集ミス等）はファイル自体は使えるので
勝手に上書きせず、直し方を伝えて終了する（利用者の編集内容を失わせない）。

### exe プロパティへのバージョン埋め込み〔済〕

`build.ps1` が `infra.__version__` からバージョンリソース（`build\version_info.txt`）を生成し、
PyInstaller の `--version-file` で exe へ埋め込む。右クリック→プロパティ→詳細で版が分かる。
版の出所は `infra.__version__` に一本化（直書きしない）。

## 都度対応・配布時の確認

- **D-D2. アンチウイルス誤検知** — PyInstaller 製バイナリはヒューリスティックで誤検知されやすい。
  `--onedir`（`--onefile` より誤検知しにくい）は採用済み。出る場合は署名するかベンダーへ誤検知報告。
  **配布前に主要な AV で一度確認**しておく。
- **配布物のサイズ実測** — `--collect-all playwright` は Node ドライバごと同梱するため 100MB 超の
  可能性がある。配布経路（メール添付の可否等）に影響するので実測する。

> **`output/` の同梱は `build.ps1` で自動化済み（都度対応から外した）。** `[4/6]` ステップで
> 空の `output/` を作り、展開時点で書き込み可否が分かるようにしている。`Compress-Archive` は
> 空フォルダを ZIP に含めないため、フォルダ保持と利用者案内を兼ねた説明ファイルを 1 つ置く。
> 狙いは `D-C1`（書き込み不可フォールバック・対応済）の権限問題に早く気づけること。

## D-D1. コードサイニング（受け口は実装済／証明書取得は組織判断で保留）

`README.md` / `USAGE.txt` は SmartScreen 警告に触れているが、**企業環境では「警告」ではなく
「ブロック」**になることがある（AppLocker / WDAC / Intune）。「詳細情報 → 実行」で回避できない
環境ではそもそも起動しない。本格配布ならコードサイニング証明書が最も効く（OV で警告軽減、
EV なら SmartScreen 評価が即付く）。年額コストと発行手続きが要るため**技術判断ではなく組織判断**。

**受け口は実装済み**: `build.ps1` に署名ステップがあり、証明書を入手したら `-CertPath`（PFX）
または `-CertThumbprint`（証明書ストア／EV トークン）を渡すだけで署名できる。指定が無ければ
素通りし未署名で配布される（従来どおり）。

### 配布先 IT へ許可登録を依頼する連絡テンプレート

証明書を取得しない間、企業環境でブロックされる場合はこれで許可登録を依頼する。
`< >` は配布ごとに埋める。SHA256 は `build.ps1` が出力する `*.zip.sha256` の値を使う。

```
件名: 業務ツール「edge-auto-capture」の実行許可のお願い

<IT 部門ご担当者> 様

業務調査で使用するツール「edge-auto-capture」を配布します。
現時点でコードサイニング署名が無いため、SmartScreen / AppLocker / WDAC / Intune の
ポリシーによってはブロックされる可能性があります。以下の実行ファイルの許可登録
（許可リストへの追加）をご検討いただけますでしょうか。

- ツール名 : edge-auto-capture
- 用途     : Web ページのスクリーンショット・テキストの自動保存（社内調査用）
- 配布物   : edge-auto-capture.zip（PyInstaller onedir 形式・未署名）
- 実行ファイル: edge-auto-capture.exe
- SHA256(zip): <build.ps1 が出力した SHA256 値>
- 依存      : Microsoft Edge / Google Chrome（同梱の Playwright ドライバ経由）
- 配布元    : <配布者名・連絡先>

ご不明点があればお知らせください。よろしくお願いいたします。
```
